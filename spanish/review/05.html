規則動詞の現在形

-ar / -er / -ir 動詞の現在形をまとめて復習する。

このStageで整理すること

  • -ar：hablo / hablas / habla…
  • -er：como / comes / come…
  • -ir：vivo / vives / vive…
  • 主語に応じた語尾変化
  • 主語省略

セルフチェック

一度自分で答えてから「答えを見る」を開く。

hablar の nosotros 形は？

hablamos

comer の tú 形は？

comes

vivir の ellos 形は？

viven
